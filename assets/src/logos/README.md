# Personal AI agent logos (v2)

Researched 2026-10-13. Scope: consumer "personal agent" products marketed to regular people as an always-on assistant you message. Coding agents excluded. Every file below was downloaded with curl, checked with ImageMagick `identify` (PNG) or an XML parse plus a headless-Chrome `<img>` render (SVG). Nothing was executed. Scratch files (favicons under 256 px, OG banners, probes) were deleted.

## Candidates checked and not shortlisted

- Perplexity Computer / Personal Computer: real (Max, then Pro/Enterprise), but a desktop "digital worker" for knowledge work, not a messaging agent; no user numbers found. v1 `perplexity.svg` still exists.
- Manus (Meta, acquired ~$2B Dec 2025): "Manus Cue" agents with their own email/phone exist in early access, but Meta is folding Manus into Muse and its apps; Muse is the consumer face.
- Microsoft Copilot / Autopilot, Gemini Spark, Claude Cowork, ChatGPT Work: work-tier features of assistants above rather than standalone consumer agents.
- Siri with agents: no shipped standalone product found in Oct 2026 coverage.
- Long tail from TechCrunch's 2026-10-10 roundup of text-message agents (Caddy, Comma, Fambot, Folk, Iris, Martin, Miso, Ohai, Ollie, Orbits, Pally, Rene, Skye, Stanley, Szn, Tomo, Town, Underdog, Wajo): none has mainstream recognition comparable to the eight above.

## Verification notes

- PNGs: `identify` reports PNG at 512x512 or larger for every file; `instinct-wordmark-og.png` is 1200x630.
- SVGs: all parse as XML with an `<svg>` root; none contain `<script>`. `grok.svg` contains a `<foreignObject>` (CSS blur backdrop from grok.com), the others are plain vectors. All rendered correctly in headless Chrome via `<img>` (contact sheets in `/tmp/delta-bags-assets/v2/check/chrome/`).
- simple-icons CDN (cdn.simple-icons.org) was unreachable from this machine, so none of the new marks came from it.
- Raw site HTML used for extraction is kept in `/tmp/delta-bags-assets/v2/untrusted-html/` and can be deleted.
