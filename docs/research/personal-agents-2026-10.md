# Personal agents vs. the Delta Bags skill (research, 2026-10-14)

Scope: can a regular person get their personal AI agent to install and auto-use the Delta Bags Agent Skill (agentskills.io format: `SKILL.md` + `references/` + `scripts/`, at https://github.com/thisiszinger/delta-bags-skill, skill dir `skills/delta-bags`) by asking in plain English, and then use it to file Delta's delayed-bag form? Product descriptions, channels, and logo provenance are in `assets/src/logos/README.md`.

Legend: **Verified** = read in an official doc/help page/README. **Inferred** = conclusion drawn from verified facts. **Not found** = looked, no evidence.

Ratings: **native skills** = the product has a first-class skills folder/CLI that accepts the agentskills.io layout and auto-selects skills by description. **workable with instructions** = no skill files, but the agent has memory/custom instructions plus enough tooling (browser or email) to follow the SKILL.md procedure if you paste or point it at the file. **not possible** = no persistent instruction mechanism, or no way to act on the web form.
